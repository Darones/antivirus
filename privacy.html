Политика конфиденциальности

Игра: «Антивирус: головоломка» (Android, NashStore)
Дата последнего обновления: 21 сентября 2026 г.

1. Общие положения

1.1. Настоящая Политика конфиденциальности (далее — «Политика») определяет порядок обработки и защиты информации о пользователях мобильной игры «Антивирус: головоломка» (далее — «Игра»), распространяемой через магазин приложений NashStore.

1.2. Разработчиком и оператором Игры является Давлеев Андрей (далее — «Разработчик»), зарегистрированный в качестве плательщика налога на профессиональный доход (самозанятый).

1.3. Используя Игру, Пользователь подтверждает своё согласие с условиями настоящей Политики. В случае несогласия Пользователь должен прекратить использование Игры.

1.4. Политика разработана в соответствии с Федеральным законом от 27.07.2006 № 152-ФЗ «О персональных данных» и требованиями магазина приложений NashStore.

2. Какие данные обрабатываются

2.1. Данные, которые НЕ собираются

  • Фамилия, имя, отчество;
  • Адрес электронной почты;
  • Номер телефона;
  • Точная геолокация;
  • Контакты, фотографии, файлы;
  • Платёжные данные (банковские карты и т.п.).

2.2. Данные, которые обрабатываются автоматически

  • Рекламный идентификатор (Google Advertising ID / GAID) — используется для показа рекламы и предотвращения мошенничества;
  • Технические данные устройства: модель, версия ОС, язык, тип соединения, IP-адрес (в обезличенном виде);
  • Игровая статистика: прогресс в кампании, количество очков, достижения, время игры — хранится локально на устройстве Пользователя;
  • Данные о сбоях: анонимные отчёты об ошибках (если предусмотрено используемыми SDK).

2.3. Разрешения приложения

  • Доступ к интернету — для загрузки рекламы и работы функции «Дуэль»;
  • Проверка состояния сети — для корректного отображения рекламы.

Игра не запрашивает доступ к геолокации, камере, микрофону, контактам, хранилищу (кроме внутреннего кэша игры).

3. Цели обработки данных

3.1. Данные обрабатываются исключительно для следующих целей:

  • Показ рекламы (в том числе вознаграждаемой) через рекламную сеть VK Ads (MyTarget);
  • Улучшение игрового процесса и исправление ошибок;
  • Сохранение игрового прогресса на устройстве Пользователя;
  • Обеспечение работы многопользовательского режима («Дуэль») через WebSocket-соединение.

4. Передача данных третьим лицам

4.1. Разработчик не продаёт и не передаёт персональные данные Пользователей третьим лицам, за исключением случаев, предусмотренных законодательством РФ.

4.2. Для показа рекламы Игра использует SDK VK Ads (MyTarget), который может собирать рекламный идентификатор (GAID) и технические данные устройства. Обработка данных осуществляется в соответствии с политикой конфиденциальности VK:

  • Политика конфиденциальности VK: https://vk.com/privacy
  • Справка VK Ads по приватности: https://ads.vk.com

4.3. В многопользовательском режиме («Дуэль») игровые данные (прогресс, счёт) передаются через WebSocket-сервер wss://antivirus-duel-server.relaxdev.ru без персональных данных. Сервер не сохраняет историю игр и не связывает данные с конкретным Пользователем.

4.4. Магазин приложений NashStore может собирать стандартные технические данные при установке Игры в соответствии со своей политикой конфиденциальности.

5. Хранение и защита данных

5.1. Игровой прогресс и настройки хранятся локально на устройстве Пользователя (localStorage) и не передаются на сервер Разработчика.

5.2. Рекламный идентификатор обрабатывается SDK VK Ads в обезличенном виде и не позволяет идентифицировать конкретного Пользователя.

5.3. Все передаваемые данные защищены с использованием шифрования (HTTPS/WSS).

6. Права Пользователя

6.1. Пользователь вправе:

  • Отключить персонализированную рекламу в настройках устройства (Google → Реклама → «Удалить рекламный идентификатор»);
  • Удалить все локальные данные, удалив Игру с устройства;
  • Отказаться от использования Игры.

6.2. Для запросов, связанных с обработкой данных, Пользователь может связаться с Разработчиком по электронной почте: daroness@ya.ru.

7. Дети

7.1. Игра имеет возрастной рейтинг 6+ и не предназначена для детей младше 6 лет.

7.2. Разработчик сознательно не собирает персональные данные детей. Если родитель или опекун обнаружит, что ребёнок предоставил персональные данные, просим связаться с Разработчиком для их удаления.

8. Изменения в Политике

8.1. Разработчик вправе вносить изменения в настоящую Политику. Актуальная версия всегда доступна по адресу: https://darones.github.io/antivirus/privacy.html

8.2. Продолжение использования Игры после внесения изменений означает согласие Пользователя с новой редакцией Политики.
